# 내야 수비 판단 훈련

VR 야구를 하는 버추얼 스트리머가 내야 수비 판단을 연습할 수 있게 만드는 웹 게임입니다.
1루수, 2루수, 유격수, 3루수 중 하나를 골라 1인칭 시점으로 상황 28개(포지션별 7개)를 플레이합니다. 목록에서 상황을 직접 고르거나, 포지션별 또는 전체 랜덤으로 연습할 수 있습니다.

- **송구 판단**: 공을 잡은 뒤 어디로 던질지 고르는 상황. 공과 주자의 도착 시간을 계산해서 판정합니다.
- **위치 판단**: 공이 나에게 오지 않을 때 베이스 커버, 백업, 중계, 커트 위치 중 어디로 갈지 고르는 상황.

모든 상황은 오른손 타자 기준입니다.

결과 화면에서 위에서 내려다보는 리플레이를 볼 수 있고, 상황별 기록은 브라우저에 저장됩니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입 검사 후 dist/에 정적 파일로 빌드
```

`dist/`는 정적 파일이라 아무 웹 호스팅에나 올리면 됩니다.
`node scripts/build-artifact.mjs <출력 파일>`을 실행하면 CSS와 JS를 인라인한 한 장짜리 HTML을 만들어요 (claude.ai 아티팩트 게시용).

## 조작

- 마우스: 시점 이동 (화면을 클릭하면 마우스가 잠기고, Esc로 풉니다)
- 클릭: 바라보는 베이스로 송구
- `A` `S` `D` `F`: 1루, 2루, 3루, 홈으로 송구 (위치 판단 상황에서는 선택지 순서대로)
- `Space`: 던지지 않고 들고 있기
- 결과 화면: `R` 다시 하기, `V` 리플레이, `N` 다음 상황, `Esc` 목록

공을 잡는 순간 슬로모션이 걸리지만 주자는 계속 뜁니다. 늦게 고르면 송구도 늦어져서 세이프가 됩니다.
난이도는 슬로모션 배율입니다 (입문 0.2배, 보통 0.35배, 실전 1배).

## 구조

| 파일 | 역할 |
|---|---|
| `src/config.ts` | 주자 속도, 송구 속도, 구속 범위, 판단 점수 가중치 등 모든 수치 |
| `src/coords.ts` | 필드 좌표계와 베이스 위치 |
| `src/field.ts` | 구장 모델링 (잔디, 흙, 라인, 펜스, 관중석, 조명탑, 전광판) |
| `src/players.ts` | 마네킹 선수와 자세 |
| `src/scenario.ts` | 상황 타입과 송구 판정 엔진 (포스, 태그, 귀루, 병살, 실점) |
| `src/scenarios.ts` | 상황 28개 데이터와 기본 수비 위치 |
| `src/timeline.ts` | 한 플레이를 시간의 함수로 만드는 곳 (공, 주자, 수비수 움직임) |
| `src/game.ts` | 게임 흐름, 1인칭 카메라, 리플레이, 입력 |
| `src/ui.ts` | 상황 목록, 브리핑, 결정 패널, 결과 화면 |
| `src/progress.ts` | 상황별 기록 저장 |

송구 판정은 "공이 베이스에 도착하는 시간"과 "주자가 도착하는 시간"을 비교해서 계산합니다. 태그가 필요한 플레이는 태그 시간만큼 불리하고, 같은 아웃이라면 태그 플레이와 먼 송구는 위험한 선택으로 보고 점수를 깎습니다.
수치는 아직 WBD 영상으로 맞추지 않은 임시값이라 `src/config.ts`에서 조정하면 됩니다.

주소 끝에 `?view=tv`를 붙이면 홈 뒤에서 내려다보는 중계 시점으로 볼 수 있습니다 (구장과 움직임 확인용).
